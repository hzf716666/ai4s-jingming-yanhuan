## 第 1 页 · 封面（约 20 秒）

[开场]

各位好，今天汇报景明研环。我想先说明一点——我们做的是**小而美**：每一项能力都是为产业创新研究这一类工作而建的，不是通用研究平台。我们挑了**三个真正的亮点**——图谱、评审漏斗、项目工作台——其它领域用不上、不该用、不能用。**每一片瓦都是为这个领域烧的**。

## 第 2 页 · 总览：三个专属亮点（约 80 秒，本页是核心，逐行讲）

[点击 · 语速放慢]

这页是整个汇报的骨架，三个亮点——图谱是**专属大脑**，评审漏斗是**专属闸门**，工作台是**专属档案室**。

**亮点 1：专属产业创新研究知识图谱**。七类节点（产业 / 园区 / 指标 / 数据文件 / 政策 / 文献 / 集群）· 592 节点 3625 边 · 12 类信号 · HLER 八字段 schema。**不是通用图谱 + 领域字典**，而是按产业创新研究的语义直接构建——火炬统计覆盖园区、OECD 跨国对照、HLER 文献锚共同构成。

**亮点 2：候选假设评审漏斗 · 把想法挡在开工前**。痛点对应方向五问 Q4 识别困难、Q5 机制黑箱。流程：Pitch → 多模型并行 → 概率平均 → 香农熵置信度 → 期刊档位映射 → 文献锚定 → 评审通过才进项目。四档评审：exceptional 对应顶级、strong 对应强顶、fair 对应中档增量、limited 对应回报不确定——**映射期刊档位**，让评审结果和发表潜力对得上。BGE-M3 本地向量库学用户偏好——否决过的假设下次不再生成。**关键**：评审不通过连工作台都不开，省下一个 GPU 小时加多轮 agent 会话的成本。

**亮点 3：研究项目级「数据快照 + 实验台账」工作台**。评审通过后，建独立项目目录、写数据快照——那一瞬间的研究假设、引用的图谱节点、置信度、变量清单全部**冻结**。七阶段流水线自动跑实验：拆解、过滤、填补、盘点、实验、写作、评审。每一步落盘到工作台，就是一份带时间戳的科研档案，**可审计、可回放**。图谱管"想什么"，工作台管"做出来什么"，中间用数据快照无缝衔接——**区别于"通用记事本 + LLM 对话"**，每次研究都是可被引用的科研档案。

**三个亮点 = 大脑 + 闸门 + 档案室**，共同构成产业创新研究的小而美。

## 第 3 页 · 方向五个真问题（约 70 秒，本页是立论）

[点击 · 语速放慢]

先退一步，回答"这个方向本身有什么问题"。Q1 单元错配：园区跨行政区划，火炬是园区口径、研究要的是城市区县口径。Q2 面板断档：火炬序列截面有限，研究只能停在静态横截面。Q3 测度存疑：专利不等于创新质量，Dang & Motohashi 2015 证实补贴催生申请虚增。Q4 识别困难：园区是择优认定非随机设立，工具变量在哪？Q5 机制黑箱：效率差异归因不清——人力资本、科技金融、制度环境哪个主导。这五问的根不是缺方法缺工具，而是**研究单元的数据资产不可得、不可信**——这正是三个亮点要解决的事。

## 第 4 页 · 亮点 1 · 专属图谱概览（约 50 秒）

[点击]

先看亮点 1，七类节点：产业（光电子、生物医药、新能源汽车等集群）、园区（东湖高新区、中关村、张江等）、指标（R&D 强度、万人发明专利、高企营收等）、数据文件（年鉴、公报、名录）、政策（高新区认定、双创政策、税收优惠）、文献（HLER 库）、集群（先进制造业集群等）。592 节点 3625 边不是爬虫堆的，是按产业研究的语义直接构建。

## 第 5 页 · 图谱深挖之一：七类节点是"专属"的依据（约 45 秒）

[点击]

为什么这七类节点就是"专属"？普通知识图谱的节点是实体——人物、地点、机构；普通研究平台的节点是文档。我们的节点是**产业研究语义层**：园区不是地点、是"创新载体"；指标不是统计概念、是"可检验命题的变量"；政策不是事件、是"识别策略的来源"。七类之间用四种边连接——**领先跟随、聚合分化、邻近溢出、政策冲击**——这四种边就是这个领域的研究模式，所以图谱是真的为产业研究构建的，不是通用图谱套字典。

## 第 6 页 · 图谱深挖之二：HLER 8 字段 schema 是"专属"的核心（约 50 秒）

[点击 · 关键页]

HLER 八字段 schema 是亮点 1 的核心技术：每条假设在图谱里不是文本，而是八个字段的**类型化对象**——X、Y、识别策略、数据粒度、因果方向、机制路径、稳健性策略、置信度档位。这八个字段覆盖了产业研究论文里"方法学完整"的全部要素。**关键**：图谱的硬约束（一票否决）检查的不是"假设是否好"而是"这个字段组合是否类型相容"——比如把"县域分层"（分类）当"VC 每专利"（比率）的控制变量，量纲不匹配，**系统直接拒**。这就是我们的小而美——通用图谱不会做这种领域专属的类型相容性检查。

## 第 7 页 · 图谱深挖之三：12 类信号是"找路"的工具（约 50 秒）

[点击]

图谱不是静态的，12 类信号识别产业研究常用模式——领先跟随、聚合分化、邻近溢出、政策冲击、时间窗口、异质性、滞后效应、稳健性、稳健性检验、外生变异、机制路径、共线性。这些信号是图谱的"探照灯"：给定一个研究问题，信号告诉你"哪些节点该连、哪些边该走"。HLER schema 提供字段、12 类信号提供方向——两者结合就是"在图谱上找路"的具体机制。

## 第 8 页 · 图谱深挖之四：图谱即证据档位、置信度四维评价（约 50 秒）

[点击]

图谱节点自带**置信度四维评价**：来源维度、一致性维度、解析通道维度、口径完整性——四维合成、过三级质检、输出高/中/低/待复核四档。低置信不丢弃，进人工复核或带标注降级；逐条归因，每条置信度能回答"哪个维度拉了后腿"。置信度作为元数据随图谱节点流转——任何下游环节（评审漏斗、工作台、影响力预测）都看得到。

## 第 9 页 · 亮点 2 · 评审漏斗概览（约 45 秒）

[点击]

亮点 2：候选假设评审漏斗。从图谱拿到候选假设之后，**先评审再开工**——这是方向五问 Q4 识别困难、Q5 机制黑箱的物理对位。

## 第 10 页 · 评审漏斗深挖之一：四档评审 + 期刊档位映射（约 50 秒）

[点击 · 关键页]

四档评审的核心不是打分，是**映射**。exceptional 对应顶级期刊（AMJ / AMR / ASQ 级），strong 对应强顶（中文权威 + 国际 B+），fair 对应中档增量（CSSCI 主流 + 国际 C），limited 对应回报不确定（适合工作论文或先做可行性）。这套映射让评审结果直接挂到发表潜力上，避免"评审说行但投不出去"。

## 第 11 页 · 评审漏斗深挖之二：多模型并行 + 概率平均 + 香农熵置信度（约 45 秒）

[点击]

评审不是单模型打分——多模型并行，每模型给四档概率分布；做概率平均，再用**香农熵**当置信度（评委越一致熵越低，熵越低分越可信）。如果熵高说明评委分歧大，要么换模型要么拒评。这把"评审一致性"做成可视化数字，不是评审说行就行。

## 第 12 页 · 评审漏斗深挖之三：BGE-M3 向量库学用户偏好（约 40 秒）

[点击]

用户偏好用 BGE-M3 本地向量库记：用户点过的 👍/👎 评价全部向量化入库，下次 regenerate 时最相似的历史评价作为 prompt 上下文。**否决过的假设下次不再生成**——这避免了反复让用户否决同一类命题，让评审漏斗越用越聪明。BGE-M3 本地离线，不上传，符合本地优先。

## 第 13 页 · 评审漏斗深挖之四：评审不通过的止损价值（约 35 秒）

[点击]

评审不通过的最大价值是**止损**：每项目约 1 GPU 小时 + 多轮 agent 会话。评审通过后才进工作台，否则连目录都不建——把低质量假设拦在数据快照之前，让 GPU 时间和数据资源不被空跑。这是评审漏斗的隐性 ROI，体现在项目数稳定增长但 GPU 浪费下降。

## 第 15 页 · 工作台深挖之一：数据快照冻结瞬间（约 45 秒）

[点击 · 关键页]

数据快照是亮点 3 的核心技术：评审通过那一刻，平台自动冻结四样东西——研究假设文本、引用的图谱节点 ID、当时的置信度档位、相关变量清单。这份快照随项目目录存盘，**三个月后还看得见当初为什么这么选**，解决了方向五问里"历史黑箱"问题。

## 第 16 页 · 工作台深挖之二：七阶段流水线落盘（约 50 秒）

[点击]

七阶段流水线：拆解 → 过滤 → 填补 → 盘点 → 实验 → 写作 → 评审。**每一步落盘**：拆解阶段的产物写进 project/scope.md，过滤写进 cleaned.md，实验写进 analysis.md，写作写进 draft.md，评审写进 review.md。**每一步有台账**：访问了图谱的哪些节点、引用了哪些数据、跑过哪些稳健性——全部可回放。这就是区别于"通用记事本 + LLM 对话"的地方。

## 备问清单（如现场被问到）

**Q1：图谱是不是"通用知识图谱 + 一个领域字典"？**
A：不是。我们从一开始就没做"通用再适配"的图谱，而是按产业创新研究的语义直接构建——七类节点固定为产业园区指标数据文件政策文献集群，节点就是创新载体、可检验变量、识别策略来源，边类型（领先跟随、聚合分化、邻近溢出、政策冲击）就是这个领域的研究模式。HLER 8 字段 schema、12 类信号、4 类边都是领域专属设计。

**Q2：评审漏斗的"四档映射 Top 期刊"是不是太主观？**
A：映射规则来自学界对经管期刊的共识分级（AMJ/AMR/ASQ 为顶级，中文权威 + 国际 B+ 为强顶，CSSCI 主流 + 国际 C 为中档，工作论文 + 回报不确定为低档），并按 500 对验证集的影响力分位做反向校准。评审漏斗评的是**想法质量**（置信度新颖性机制识别 + 期刊档位），影响力预测评的是**发表潜力**（同领域同年归一化引用分位），两轴正交、配色不同，不混淆。

**Q3：数据快照冻结"瞬间"——这不是把研究僵化了吗？**
A：不会。冻结的是那一瞬间的"决策依据"——研究假设文本、图谱节点、置信度、变量清单。如果后续假设要改，新建项目目录、写新快照；旧快照依然在，可对比"前后两次为什么改、改了什么、改后效果如何"。快照是科研档案的颗粒度，不是研究思路的锁。

**Q4：评审漏斗的"评审一致性"和影响力预测的"分位"是两套吗？**
A：是的，分开用：评审漏斗评"想法值不值得做"，用香农熵做一致性；影响力预测评"做出来大概能发在哪"，用同领域同年归一化引用分位。两者并列、配色不同——评审沿用现有 TIER 色，影响力用蓝紫色系，不混淆。

**Q5：三个亮点是不是"通用平台 + 领域适配"？**
A：不是。每个亮点都有领域专属的"硬约束"：图谱有 HLER 8 字段的类型相容性检查；评审漏斗有期刊档位映射（不是给个"4 分"就完事）；工作台有数据快照冻结（不是普通的项目目录）。这三件事拿到别的领域用不动——HLER schema 不适用于医学论文、期刊档位映射不适用于 CS 顶会、数据快照冻结不适用于一次性数据探索。**小而美的代价是不通用，但换来了"专属"**。

**Q6：项目工作台和"通用记事本 + LLM 对话"的根本区别？**
A：四点。一，工作台冻结数据快照，记事本不冻结；二，工作台七阶段落盘，每步落盘对应产物文件，记事本只有对话流；三，工作台有实验台账可回放访问了哪些节点、跑了哪些稳健性，记事本没有台账；四，工作台项目目录可被引用为科研档案，记事本只能引用对话链接。**根本区别是"科研档案的颗粒度"**——前者是项目级，后者是会话级。

**Q7：方向五问是不是"先有结论再找问题"？**
A：不是。每问都指到文献或制度依据：单元错配是火炬口径与行政区划的客观矛盾，面板断档是序列可得的客观限制，测度存疑有 Dang & Motohashi 2015 的因果证据，识别困难是园区择优设立的制度事实，机制黑箱是多维数据缺位的直接后果。
