# 科技园区创新研究：从方向问题到研究成果的研究流程

2026-09-04 ｜ 配套：方向问题清单见 `2026-09-04-科技园区创新研究方向问题与项目映射.md`；汇报见 `docs/report/景明研环-数据痛点与架构-动画汇报.html`（第 3、9-14、16-21 页）

> **一句话定位.** 这是一条"先看方向的问题，再用平台把每个问题接住"的研究流程。
> 全程七步，每一步都能挂回"科技园区创新研究"的真实场景、真实变量、真实瓶颈，每一步也都有平台功能对应——不是流程图，而是"我能在这个流程的哪一步被它接住"。

---

## 一、流程全景：七步实证研究流水线

```
[问题] → [数据] → [假设] → [设计] → [实验] → [写作] → [预演]
   1       2-3       4         5         6        7         (回看)
   ↓       ↓         ↓         ↓         ↓        ↓
 直觉     多源       图谱       DID/DEA   跑回归    经管实证   影响力
 锚定     数据底座   候选假设   识别策略  +稳健性  论文模板   预演 + 台账
```

七步不是线性递进，而是一条**双回流的闭环**——写作（7）前的可复现性验证（6 末）可以驱动数据返工（2-3）；影响力预演可以驱动假设与实验的迭代（4-6 末→2-3 与 4-5 头）。

---

## 二、流程七步（每步：做什么 · 真实场景 · 平台在哪接）

### 第 1 步 · 方向锚定：从"研究兴趣"到"可写命题"

**做什么.** 把"我想研究高新区创新"这种兴趣词,翻译成 1 句可写的命题草稿,并初步验证它在领域内是否被做过。

**真实场景举例.**
- 兴趣词: "我想研究高新区创新效率差异"
- 命题草稿: "国家级高新区 2019-2024 年 R&D 强度对人均专利产出的弹性,东中西三类园区是否异质?"
- 验证重点: "R&D→专利"是经典命题, 但"分园区类别异质"是否被做穿? 已有研究止步于全国均值还是分东中西?

**平台怎么接.**
- **方向问题清单**作为锚 (见 `2026-09-04-科技园区创新研究方向问题与项目映射.md` 五个问题: 单元错配 / 面板断档 / 测度存疑 / 识别困难 / 机制黑箱)——这五个问题就是"做这个方向的代价清单"
- 文献检索 + 向量召回 (BGE-M3): 看命题是否已被做穿
- 用户表 + 偏好记忆: 跳过用户已否决的方向

**踩坑提示.** 这一步最容易的不是"想不出来", 而是"想到的命题在数据上根本不可行"——比如想做园区层面的"风险投资进入对专利质量的影响", 数据上火炬统计根本不公布 VC 流入。这是后面第 2 步倒回来最常见的理由。

---

### 第 2 步 · 数据盘点: 从命题到变量清单

**做什么.** 把命题翻译成**变量清单**——每个变量从哪取、口径是什么、置信度够不够; 并构造"研究单元 × 变量"的初步面板。

**真实场景举例 (续前命题).**
- 因变量: 人均发明专利拥有量 (火炬统计 · 园区层级, 2019-2024)
- 自变量: R&D 强度 = R&D 经费 / 园区营业收入, 滞后 2 年 (Griliches 1979 经典设定)
- 控制: 高企数量 / 高校院所数 / 外资企业占比
- 调节变量: 园区类别 (东部 / 中部 / 西部) 哑变量

**平台怎么接.**
- **五管线解析** (xlsx / PDF / OCR / 图表逆向 / Word-PPT): 把年鉴、公报、园区名录里的指标抽出来
- **七层管线** (结构感知→视觉取数→OCR→语义对齐→量化逆向→证据裁决→输出落地) 解决"扫描件、图表藏数、多级表头取零行"四类问题
- **四档证据链** + **置信度四维评价** (来源 / 一致性 / 通道 / 口径): 每个变量都带置信度标注
- **数据年份 as-of 标注**: 火炬 2019-2024 实际只有 2024 / 2025 两卷, 早年用 OECD MSTI + 各省统计公报交叉补
- **可加总性钩稽**: 园区子单元之和 ≈ 城市总量, 误差超限即标记

**踩坑提示.** 命题再"漂亮", 关键变量拿不到就是死命题——所以这一步实际是"用变量去**倒逼命题**", 把命题改到能跑为止。

---

### 第 3 步 · 口径治理: 让面板"同口径"

**做什么.** 让多源、多表头、多时点的数据在同一面板里口径一致, 包括单位换算、名称归一、口径注解。

**真实场景举例.**
- "东湖高新区" = "武汉东湖新技术开发区" = "光谷" — 三个名字一个对象, 全部要归到同一 ID
- R&D 经费 "亿元 / 万元 / 人民币 / 美元" 换算; 名义 vs 实际 (用 GDP 平减指数折算)
- 火炬统计 vs 统计公报同一指标数值差 5%-10%: 哪个为准?——以**园区口径**为准, 公报作为印证 (双轨制下的明示选择, 不是 bug)

**平台怎么接.**
- 实体对齐 (园区名中英混排清洗 + 行政区划代码映射)
- 单位换算 (同义词映射 + 别名字典)
- 口径注解 (每个变量都带 "来自 X 文件 / 口径 X / as-of YYYY")
- 量化逆向 (增速反推绝对量, 占比×总量恢复)
- 文献必引门禁 (Dang & Motohashi 2015 必引 — 提醒读者专利质量虚增问题)

**踩坑提示.** 口径一旦在面板里"静默统一", 失真也无从查; 平台把口径注解和 as-of 标注**强制**带在每个变量上, 而不是可选。

---

### 第 4 步 · 假设生成: 从变量组合到"可检验命题"

**做什么.** 把变量清单组合成若干候选假设, 每个假设带"假设文本 + 数据支撑 + 置信度 + 文献锚 + 可复现性检验"。

**真实场景举例 (续).**
- H1: 国家级高新区 R&D 强度每提升 1 个百分点, 两年后人均发明专利拥有量提升 X 件 (95% CI)
- H2: 该效应在东部强于中西部 (交互项显著)
- H3: 机制 — 高企数量与高校院所数的中介效应显著

**平台怎么接.**
- **图谱找路** (FKG 592 节点 / 3625 边): 哪些变量组合有真数据支撑, 图谱先答
- **硬约束否决** (样本不足 / 数据缺失 / 无法验证 / 文件冲突 / 与对象不符): 一票否决, 杜绝"灵感型"假设
- **向量语义检索** (BGE-M3): 召回相关文献, 看是否被做过、证据站哪边
- **多轮评审** (置信度 / 新颖性 / **机制** / **识别** 四轴, BGE 校准 0.40): 从"我感觉行"到"证据说行"
- 输出: **候选假设档案** — 假设、数据、置信度、可复现性检验、文献锚, 全部标"候选", 不冒充结论

**踩坑提示.** 这一步最容易"灵感膨胀"——想到一堆候选, 评审来不及一一评分; 平台的硬约束和四轴评审把"灵感"压回"证据可检验"的范围。

---

### 第 5 步 · 识别设计: 让因果可信

**做什么.** 把候选假设转成"识别策略 + 实证设计": 用什么估计量 (OLS / FE / DID / RDD / IV), 内生性来自哪、用什么工具变量或平行趋势检验来对冲。

**真实场景举例.**
- 内生性来源: 园区认定非随机 (择优设立), 创新投入与产出可能反向因果
- 识别策略: 高新区批次设立做 DID, 用 1991 / 1997 / 2009 / 2012 等批次作为政策冲击; 平行趋势检验 + 安慰剂
- 工具变量候选: 园区到最近省会城市的距离 (参考 Wang 2013 经济区研究)

**平台怎么接.**
- 评审四轴中的**识别轴**: 自动检查"工具变量是否被讨论过 / 平行趋势是否被检验过 / 处理组与对照组可比性"
- 图谱锚定政策时点: 园区认定批次的官方时间节点入图, 作为 DID 冲击
- 假设档案中"识别可行性"标注: 候选假设必带识别策略说明, 不带则评审直接扣分

**踩坑提示.** 这一步最容易被评审专家一句话打回: "你的内生性呢?"——把识别设计**前置**到假设阶段, 比事后补救更稳。

---

### 第 6 步 · 实验执行: 跑回归, 做稳健性, 写图表

**做什么.** 实证分析 (基准回归 + 异质性 + 稳健性), 输出图表与统计描述, 同步做内容级抽检与可复现性验证。

**真实场景举例.**
- 基准: 双固定效应 (园区 + 年份) 回归; 滞后 2 年的 R&D 强度对人均专利
- 异质性: 分东中西三组子样本回归
- 稳健性: 替换因变量 (申请 vs 授权 vs 拥有量三口径); 替换自变量 (R&D 经费 vs R&D 强度); 缩尾; 内生性处理 (DID / IV)
- 图表: 三类园区系数对比柱图 + 平行趋势图 + 异质性子样本对比

**平台怎么接.**
- 八步流水线 (拆解 / 过滤 / 填补 / 盘点 / 实验 / 写作 / 评审 / 结果): 平台默认实验执行在 L5 落成流水线
- 自动汇总核验: 多重检验下的显著性可信度, 跑出 p<0.05 还要看是否在多重检验校正后仍然显著
- 偏差自查: 异常值 / 缩尾前后系数差 / 内生性稳健性检查
- 内容级抽检 (LAED 式): "confidence-only, 不代改"——不替作者改文章, 只报告哪里可疑

**踩坑提示.** 显著性跑出来容易, "稳健性也通过" 难——把替换变量、缩尾、内生性处理**作为必备检查项**, 而不是可选。

---

### 第 7 步 · 写作与预演: 从结果到"可被复现的稿件"

**做什么.** 把图表与回归结果写成可投稿稿件, 同步做影响力预演、偏差自查、台账归档——把"后验"变成"预演"。

**真实场景举例.**
- 经管实证八节模板: 引言 / 文献 / 制度背景 / 数据 / 实证设计 / 结果 / 机制 / 结论
- 写作中嵌入: 每个数字的来源页码 (溯源链)、口径注解、as-of 标注、稳健性检查清单
- 投稿前: 影响力预演 (同领域同年归一化引用分位), 偏差自查清单完成, 台账归档

**平台怎么接.**
- 影响力预测 (19,970 篇经管语料 / 500 对验证集 / 双通路 0.6/0.4 / 零样本上线): 投稿前预演影响力位置
- 评审引擎 (置信度 / 新颖性 / 机制 / 识别 四轴): 写作时实时检查稿件质量
- 自动汇总核验: 数字与证据链、置信度、口径注解的对齐
- 台账回放: 每一步可回放, 审稿人来问"为什么这么选", 台账直接答
- 文献必引门禁: Dang & Motohashi 2015、Griliches 1979、Hu 2007、Wang 2013 必引, 防漏

**踩坑提示.** 写作完成后, 影响力预演能告诉你**这篇大概会被谁引用、引用分位在哪**——把投稿从"等半年看命运"变成"先预演一遍, 再上场"。

---

## 三、双回流: 闭环是怎么跑起来的

七步不是单向流水线, 而是两条回流:

**回流 A · 实证验证回流到假设 (第 6 末 → 第 4-5 头)**
实验跑出来系数不显著或稳健性差, 提示假设本身有缺陷——回流到第 4 步, 让图谱重新找路、评审重新打分。这是 "假设有据" 的**事实校准**。

**回流 B · 写作中发现的数据缺陷回流到面板 (第 7 中 → 第 2-3 头)**
写作时发现某个变量的口径变化在面板里没处理干净, 立即回流到第 2-3 步重新治理, 而不是"先发出去再说"。这是 "数据可信" 的**过程校准**。

这两条回流让研究不是"线性流水线", 而是"边做边校准的螺旋"——也是平台把传统研究的"一次性提交"变成"持续可回放"的关键。

## 五、这套流程能解决的问题 (对应方向五问)

| 流程步骤 | 对应方向问题 | 解决机制 |
|---|---|---|
| 第 2-3 步 数据 + 治理 | Q1 单元错配 / Q2 面板断档 / Q3 测度存疑 | 实体对齐 + 多源补数 + as-of 标注 + 指标白名单 (申请/授权/拥有量三口径强制分离) |
| 第 4 步 假设生成 | Q4 识别困难 (前置评审) / Q5 机制黑箱 | 图谱锚定政策时点 + 硬约束查识别可行性 + 多维边支撑机制型假设 |
| 第 5-6 步 实验 | Q3 / Q4 / Q5 | 替换变量 + 缩尾 + 内生性处理做必备检查; 评审引擎四轴自动核查识别 |
| 第 7 步 写作 + 预演 | (写作期新问题) | 影响力预演 + 台账回放 + 文献必引门禁 |
| 全程 | 不可见错误 | 内容级抽检 (LAED 式, 只报告不代改) + 自动汇总核验 |

## 六、小而美的落点 (与方向五问文档呼应)

按"一个问题做穿"原则, 在这套流程里**先把"园区创新效率"做透**:
- 第 1 步锁定命题: 国家级高新区 R&D→专利, 分东中西异质
- 第 2-3 步建面板: 178 家国家级高新区 + 名录 + 双轨制数据
- 第 4-5 步生假设: 知识生产函数 + 异质性 + 机制假设
- 第 6 步跑回归 + 稳健性 (申请/授权/拥有量三套口径都跑)
- 第 7 步写作 + 影响力预演

这是"**一个问题做穿**"的样本, 也是平台能力的小而美展示。其它问题 (集聚溢出 / 政策效应 / 网络异质) 留作后续——先把一个问题立住。

| 全程回放 | L5 末→L1 回流 | 运行台账 + 实验结果与置信度回流 |
