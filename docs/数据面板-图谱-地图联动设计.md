# 数据面板 · 知识图谱 · 数据地图 三页联动设计 (v1)

> 目标:把"抽取→面板→图谱→地图"串成一条证据链。数据面板是**唯一事实源**;图谱和地图只是它的两种视图,所有跳转都汇回数据面板看证据。
> 2026-09-01 基于现有实现(fact_records 表已含 source + confidence 标注)设计。

---

## 1. 核心概念:DataItem(数据条目)

数据面板的每一行 = 一条 **DataItem**。用户口中的"全国GDP这一条数据"对应一个 DataItem;它可能有多条来源(从不同 PDF/Excel 抽取),多条来源相互印证。

### DataItem 结构

```ts
interface DataItem {
  key: string;                 // 唯一键: indicator + space + year (聚合键)
  indicator: string;           // 指标名, 如 "营业收入" / "人口"
  space: string;               // 空间, 如 "湖北省" / "武汉" / "合计"
  year: string | null;         // 时间, 如 "2024" / null(截面)
  value: number | null;        // 选定值(多源时取 top_val/众数/中值)
  unit: string;
  confidence: "high" | "medium" | "low";
  confidenceScore: number;     // 0-100, 由来源数/一致性/来源质量计算
  reviewStatus: "auto" | "pending_review" | "reviewed";  // 低置信度→pending_review→人工
  reviewNote?: string;
  evidence: EvidenceEntry[];   // 全部来源, 按可信度排序
}
interface EvidenceEntry {
  sourceId: string;            // fact_records.id
  source: string;              // "火炬年鉴 ... / 1-10_xxx.xlsx / sheet=1-2"
  file: string;                // 文件名(从 source 解析)
  table: string;               // 表名
  value: number | null;
  extractedAt: string;
  pipeline: string;
  quality: number;             // 来源质量 0-100
}
```

### 聚合规则(后端)

`SELECT indicator, space, year ... GROUP BY` 后:
- **value**: 多条来源值一致 → 取该值,confidence 高;不一致 → 取 top_val(出现次数最多),差异 > 阈值 → 建议人工
- **confidenceScore** = 0.45×sourceCount + 0.25×sourceQualityAvg + 0.30×consistency(一致=100, 冲突=0)
- **reviewStatus**: confidenceScore < 60 或存在冲突 → `pending_review`,数据面板标黄;人工点"通过"→ `reviewed`。

### 2.1 数据面板 `/data/records`(新建页, 核心)
- **列表**: 每个 DataItem 一行(指标 / 空间 / 年 / 值 / 单位 / 置信度徽章 / 来源数 / 审核状态)
- **筛选**: 指标名搜索、空间、年份、置信度(全部/待审/已审)
- **详情(展开或右侧抽屉)**:
  - 值 + 置信度分数条
  - 证据列表: 每个来源一行(文件→表→值, 带 "从 1-10_xxx.xlsx / sheet=1-2 抽到" 的溯源)
  - 相互印证: 来源值一致/冲突用颜色标注; 冲突来源高亮, 供人工裁断
  - 人工审核: "通过" "修改值" "标记低可信来源" → 更新 reviewStatus
- **快捷跳入**: 支持 URL 参数 `?indicator=营业收入&year=2024` 直接定位

### 2.2 知识图谱 `/data/knowledge-graph`(重做页)
双视图 tabs:
- **数据视图(默认, 与数据面板同源)**: 节点 = DataItem(按 indicator 聚合的可视化), 边 = 共享来源/同表共现。点节点 → 跳 `/data/records?indicator=xxx` 看证据。节点配色按置信度(绿/黄/红), 尺寸=来源数。
- **研究视图(保留 FKG)**: 现有双集群融合研究图谱(218节点), 美学重做(见 §4), 加"跳转数据面板"按钮(针对有 indicator 对应的节点)。
- 若 `/api/records` 无数据(未抽取), 数据视图显示空态引导去抽取页。

### 2.3 数据地图 `/data/map`(小改)
- 指标 chip 增加来源角标: 显示该指标对应 DataItem 数量; 点击 chip **不改变行为**, 但新增右侧"⚡ 查看数据来源"按钮 → `/data/records?indicator=<指标>`
- 地图柱/区域气泡 tooltip 新增 "该指标数据来源: N 条(点我→面板)" 链接

### 2.4 抽取流水线(已有, 只加收尾)
- 结果页新增 "存入数据面板" 步骤展示: 提醒多少条落库、多少条 pending_review; 一键跳 `/data/records`

## 3. 后端改动(最小化)

- 新端点 `GET /api/records`:
  - 从 `fact_records` 读全部行, 按 (indicator, space, year) 聚合 → DataItem[]
  - `?indicator=&space=&year=&status=` 过滤
- 新端点 `GET /api/records/{key}`: 单条目(含 evidence 全列表)
- 新端点 `POST /api/records/{key}/review`: 保存 reviewStatus/reviewNote(写 `record_reviews` 表, `CREATE TABLE IF NOT EXISTS`)
- 置信度计算放后端; API 返回结构即 §1 DataItem

> 不做 GNN/嵌入——先用确定性聚合让链路跑通, 复杂评分后续升档。

## 4. 图谱页美学重做清单

现有问题: 218节点/729边 力导向一团乱、label 溢出、无层级、无搜索、配色刺眼。

重做方案(研究视图, ECharts graph):
1. **分层布局**: 不在散开力导向。Region/都市圈 → 外环; Cluster → 中环按产业分组; Instrument/Policy/STCluster → 内环。用 ECharts `layout:none` + 手工坐标(同心圆/分组扇形), 或 `force` 加大 repulsion 但按 category 初始化坐标。
2. **抑制长标签**: label 默认只显示"短名"(前 8 字), hover 才全名; 或开 `labelLayout:{hideOverlap:true}`。
3. **视觉降噪**: 派生边(co_located/co_mentioned)默认折叠成"聚合环"(显示"13 个武汉集群同区"), 观测边细线; 图例可切换显示哪类边。
4. **交互**: 搜索框(按名称过滤+聚焦)、维度滑块(阶段 filter)、点击节点右侧显示属性、双击 → 若节点有 indicator 跳数据面板。
5. **配色**: 低饱和、同色系渐变(Cluster 橙→深橙按绩效; Instrument 红→粉按阶段; Region 灰蓝), 背景浅色面板风格(与应用主题一致, 不突兀)。

数据视图直接用 ECharts graph + `/api/records`: 节点数 = DataItem 数(几百), 按 indicator 聚合成"指标超节点"→数据子节点(可用 `categories` 分组); 边 = 同文件证据(evidence.source 相同)。

## 6. 验证口径

- 一个真实 DataItem(如"湖北省营业收入×合计×2024")在: 面板有 N 个来源、图谱点节点跳回面板、地图该指标可跳面板 —— 三处指向同一 key。
- 低置信度条目出现在"待审核"过滤; 人工点通过后状态持久化(重启仍在)。
