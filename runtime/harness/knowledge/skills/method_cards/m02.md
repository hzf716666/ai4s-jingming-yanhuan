# m02 方法卡 | 均值差异 t 检验(含 Welch)

## 适用场景
Y 是连续变量,分组比较两组均值差异(如 高企占比高的集群 vs 低的)

## 数据要求
两组连续值 + 组标签

## 识别假设
截面关联,无因果

## 代码模板
```python
from scipy import stats
t,p = stats.ttest_ind(a,b,equal_var=False)
d = (a.mean()-b.mean())
se = (a.var()/len(a)+b.var()/len(b))**0.5
# coef=d se=se ci=[d-1.96se,d+1.96se] p=p effect_size=cohens_d
```

## 输出解读规范
Welch 不假设方差齐;N<15/组 谨慎

## 湖北数据可适用性预判
⚠️ 65 集群分组后组内常 <15 → 配 m12 Bootstrap

## 护栏联动
- estimates 必须含 coef/se/ci_95/p/n/effect_size
- N<30 → 配 m12 Bootstrap;显著结论须 ≥2 稳健性检验
