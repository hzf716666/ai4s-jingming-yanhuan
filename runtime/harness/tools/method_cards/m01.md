# m01 方法卡 | 比例检验 + 二项检验(组间占比差异)

## 适用场景
X 是二元/占比指标,Y 是分组或占比,检验两(多)组占比是否显著不同。H-A1-S1 型(专利占比 vs 集群占比失衡)

## 数据要求
两组计数(n_i, k_i)或占比 + 分母

## 识别假设
截面关联,无因果。causal_claim=false

## 代码模板
```python
import json, math
p1,p2 = k1/n1, k2/n2
p = (k1+k2)/(n1+n2)
se = math.sqrt(p*(1-p)*(1/n1+1/n2))
z = (p1-p2)/se
# coef=p1-p2 se=se ci=[coef-1.96se, coef+1.96se] p=2(1-norm.cdf(|z|)) effect_size=coef
```

## 输出解读规范
coef=占比差;CI 跨 0 则差异不显著;样本小(N<30)换 Fisher 精确检验

## 湖北数据可适用性预判
✅ H-A1-S1 直接用:三都市圈占比(89% vs 61.4%…),分母=57 集群

## 护栏联动
