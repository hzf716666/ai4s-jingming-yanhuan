# Paper Revision — Methodology
> Extracted from ARC Stage 19: `_paper_writing.py` revision logic

## Revision Flow
1. Read reviews.md + revision_checklist.md
2. Address each checklist item systematically
3. Re-draft affected sections
4. Length guard: prevent uncontrolled expansion
5. Re-validate word counts and citation format

## Revision Principles
- Address ALL reviewer comments (accept or rebut)
- If reviewer requests additional experiment → trigger 实验执行
- Maintain narrative coherence across revisions
- Do not introduce new unsupported claims
