# 指标口径字典（metrics dictionary）

> 作用：项目内存放 `空间×年份×指标` 面板数据时，对每个指标登记**口径定义、单位、来源**，
> 避免跨表合并时口径断点（如"营业收入"百万/万元、专利"件/件·万人"）。盘点探针
> `probe_profile.py` 检查口径一致性也以此字典为准。本文件为骨架：新指标入库时补条目。

## 条目模板

```markdown
### <指标名>
- 定义：
- 单位：
- 粒度（space/time）：
- 口径断点：（如 2015 前后统计口径变化）
- 来源：
- 在案数据：<文件/表>
```
