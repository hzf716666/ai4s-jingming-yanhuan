# m04 方法卡 | 面板固定效应(region×year)

## 适用场景
time×space×indicator 面板数据的主回归卡;双固定效应吸收空间/时间不变量

## 数据要求
面板:unit, year, Y, X, controls

## 识别假设
FE 吸收单位/年份固定效应;仍观测性,无外生冲击仍非因果

## 代码模板
```python
import statsmodels.formula.api as smf
m = smf.ols('Y ~ X + C(unit) + C(year) + controls', data=df).fit()
# 或 linearmodels.PanelOLS(Y ~ X + EntityEffects + TimeEffects)
```

## 输出解读规范
报告 FE 模型 coef + cluster(unit) SE + CI;平行假设不能被吸收 → 注明

## 湖北数据可适用性预判
⚠️ 现有面板年份少(2023/2024 两截面)不满足严格 FE,降级 m03

## 护栏联动
- estimates 必须含 coef/se/ci_95/p/n/effect_size
- N<30 → 配 m12 Bootstrap;显著结论须 ≥2 稳健性检验
