# m07 方法卡 | IV-2SLS

## 适用场景
内生解释变量需工具变量;如 集群 VC 对绩效(VC 受区位内生影响)

## 数据要求
工具变量 Z(外生+相关性可论证)

## 识别假设
排他性约束;必须报告 first-stage F>10 + 过度识别(多工具)

## 代码模板
```python
from statsmodels.sandbox.regression.gmm import IV2SLS
# 或 linearmodels.IV2SLS(Y~1+controls,[X],[Z])
```

## 输出解读规范
2SLS 效应通常大于 OLS;识别强度不足 = 无信息

## 湖北数据可适用性预判
❌ 缺可信工具变量 → 暂缓

## 护栏联动
- estimates 必须含 coef/se/ci_95/p/n/effect_size
- N<30 → 配 m12 Bootstrap;显著结论须 ≥2 稳健性检验
