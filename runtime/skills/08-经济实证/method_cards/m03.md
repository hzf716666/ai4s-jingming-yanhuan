# m03 方法卡 | Spearman/Pearson 相关 + 偏相关

## 适用场景
两个连续/有序变量的单调关联;也可用于结构指数与结果变量的相关性

## 数据要求
两列数值,同空间单元对齐

## 识别假设
关联(无因果),报告 rho 与 CI(Bootstrap)

## 代码模板
```python
from scipy import stats
rho,p = stats.spearmanr(x,y)
# 偏相关: 控制 z 时用 pingouin.partial_corr
# coef=rho se=bootstrap_se ci=[rho-1.96se,rho+1.96se] p=p
```

## 输出解读规范
rho 单调关联不意味着线性;N<20 只报告描述级

## 湖北数据可适用性预判
✅ 适用;但样本极小(N<20)时仅描述级,不进回归

## 护栏联动
- estimates 必须含 coef/se/ci_95/p/n/effect_size
- N<30 → 配 m12 Bootstrap;显著结论须 ≥2 稳健性检验
